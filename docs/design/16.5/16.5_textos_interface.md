# Pacote 16.5 · Textos da interface (hoje → proposta → motivo)

**Versão:** 22/09/2026, revisada em 23/09/2026 (legendas e cabeçalho cumulativo). **Fonte do "hoje":** `index-dev.html` (Pacote 16.4.2), lido do repositório. **Especificação completa:** documento "Pacote 16.5 — análise dos seus comentários", aba "Pacote 16.5 · versão atualizada".

**Regra:** nenhum texto da interface muda sem um motivo desta lista. Onde não havia motivo, o texto de hoje foi mantido, mesmo quando a prancha do Design propunha outro. Use a coluna "Proposta" e a seção "O que fica igual". O conteúdo clínico (itens, grupos, legendas, "Outro", perguntas de ajuda) está no arquivo `16.5_catalogo_automonitoramento.md` e não muda.

Linhas marcadas com D3, D6, D9, D11, D13 ou N1 dependem de confirmação do Vinícius; a proposta abaixo é a recomendada.

| Motivo | Quando se aplica |
| --- | --- |
| Tela | A tela saiu ou mudou de função |
| Falso | O texto diz algo que o sistema não faz, ou confunde |
| Vocabulário | Conflito com os termos clínicos fixos |
| Consistência | A mesma coisa tinha dois nomes ou dois verbos |
| Repetição | Repetia o que a barra já diz (o mesmo critério do 16.1) |
| Digitação | Erro de digitação |
| Novo | O layout novo precisa de um texto que não existia |
| Decisão | Decisão do Vinícius no documento do pacote |

## O que fica igual

- Todo o conteúdo clínico (arquivo do catálogo): itens, títulos e descrições dos grupos, "Outro:" com "especifique...", as 3 legendas, as perguntas de ajuda dos pensamentos e as 5 frases da caixa descritiva do humor.
- As instruções de cada etapa (exceto o erro de digitação), "Tipo de Contexto", "Tipo de Pensamento", "Tipo de Comportamento" e as frases que os acompanham.
- As dicas dos campos de Pensamentos e Comportamentos, "+ Adicionar outro pensamento" e "Precisa de ajuda? Veja perguntas que podem guiar sua reflexão".
- Os nomes e as descrições dos cartões Registro Negativo e Registro Positivo.
- "Como Usar Este Registro" e o seu conteúdo, "Painel de Evolução", "Concluir e Revisar", "Enviar Registro" e o botão "Novo registro" do Início.

## Textos das pranchas da v1 que não entram

| Texto da prancha | Por que não entra |
| --- | --- |
| "Gravar registro", "Registro gravado" | O sistema usa "Enviar" |
| "Registrar também algo que fez bem hoje" | Reduz a definição do Registro Positivo, que inclui situações conflituosas |
| "O Vinicius vê isso antes da sua sessão de quinta", "Depois de gravar, só o Vinicius pode alterar" | Nome fixo num sistema com vários profissionais; o sistema não tem sessões cadastradas; o paciente pode corrigir |
| "o 13º do mês", "cerca de 3 min" | Contagem e tempo que o sistema não mede |
| "nenhuma é obrigatória" | Contradiz a obrigatoriedade de hoje (D9) |
| "o progresso fica salvo se você fechar a aba" | Falso: o rascunho some quando a aba é fechada |
| "O que o corpo fez?", "O que você fez?", "O que passou pela sua cabeça?", "Esse pensamento é sobre", "Quanto você acreditou nele?" | Substituídos pelos rótulos que já existem |
| "Solitária", "Sem vontade", "Falta de ar", "Adiei a tarefa" e os demais itens reescritos | Conteúdo clínico reescrito ou inventado: vale o catálogo |
